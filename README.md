Batch-checkbox-assistant
批量答题助手 – 一键提取题目、截图、根据json自动勾选答案

本代码由 heichengljy 与 AI 合作完成

📌 简介
Batch-checkbox-assistant 是一款浏览器扩展，专为在线考试/练习页面设计。
它能够自动识别学习通（超星）考试界面和通用复选框/单选框页面，
一键提取题目内容（含文字和图片），配合你喜欢的 AI（如 ChatGPT、DeepSeek 等）生成答案，并自动填充勾选。
相比手动搜题和点选，本工具可节省约 70% 的时间，尤其适合长题目和大量选择题。

一键提取题目
纯文字页面：一键复制题目+预置提示词，直接粘贴给 AI。
含图片的题目：内置长截图工具，可滚动截取整个页面，将截图发送给支持图像识别的 AI。

智能答案回填
AI 返回 JSON 格式答案（如 {"1":"B","2":["A","C"]}），扩展自动解析并逐个勾选对应选项，支持单选/多选/判断题。

🚀 安装步骤
由于本扩展未上架 Chrome 网上应用店，请按以下方式手动加载：

Chrome/Edge：地址栏输入 chrome://extensions/ 或 edge://extensions/

开启 开发者模式（右上角开关）。

加载未打包扩展
点击 “加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。

固定扩展（可选）
点击浏览器工具栏的拼图图标，将“批量答题助手”固定，方便使用。

📖 使用指南
第一步：打开目标页面
进入学习通考试页面，或任何包含单选/多选/判断题的网页。

第二步：打开扩展弹窗
点击浏览器工具栏中的扩展图标，弹出助手面板。

第三步：检测页面支持
扩展会自动检测当前页面，若支持，状态会显示为 ✅ 学习通页 或 ✅ 复选框页。
若显示 ❌ 非支持页，请确认页面已完整加载。

第四步：提取题目并喂给 AI
纯文字题目：点击 “复制喂AI”，提示词+题目已复制到剪贴板，粘贴到 AI 对话框即可。

含图片的题目：点击 “截图保存”，扩展会滚动截取整个页面（支持取消），截图自动存入剪贴板，然后粘贴到支持图像识别的 AI。

第五步：执行 AI 返回的答案
AI 根据题目内容生成 JSON 格式答案（示例：{"1":"B","2":["A","C"],"3":"A"}）。

将 JSON 粘贴到扩展弹窗下方的文本框中。

点击 “立即执行”，扩展将自动滚动到每个题目并勾选对应选项。

⚙️ 配置说明
点击扩展弹窗右上角的 ⚙️ 设置 可进入配置面板，包含两个标签页：

核心设置
选项点击间隔：控制每个选项点击后的延迟（1ms~70ms），数值越大越稳定，但执行速度会变慢。

自定义 AI 提示词：可修改题目前/后的提示语，适应不同 AI 的需求（修改后自动保存）。

截图设置
截图间隔：每次滚动后的等待时间，页面加载较慢时可增大。

裁剪范围（起始线 / 步长线）：

起始线（红色）：视口顶部向下 X% 处开始裁剪。

步长线（蓝色）：视口顶部向下 Y% 处结束裁剪，步长为 Y-X（视口百分比）。

调整后可在页面上实时看到辅助线，便于优化截图质量。

点击 “恢复默认设置” 可一键重置所有选项。

📝 注意事项
仅供学习研究使用，请勿用于考试作弊，遵守学术诚信。

请确保页面完全加载后再使用截图或提取功能。

如果截图失败，可尝试增大“截图间隔”或调整裁剪比例。

长截图功能存在浏览器速率限制，扩展已内置重试机制，若连续失败，可稍后再试。
